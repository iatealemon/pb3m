# Changelog

## [1.1.0] - 2026-09-06

### Added
- Keybinds/actions added by PB3 are now shown in the context menu
- The userscript will now detect if it is already running
- Changelog

### Changed
- Rebound the "Rename Symbol" action to Alt+F2 so it doesn't conflict with PB3's toggle fullscreen keybind
- The PB3M license text is now also included in the userscript
- Modified AceEditorAdapter.commands.addCommand to accept more than a hardcoded list of keys

### Fixed
- Fixed bug where PB3's toggle fullscreen keybind wasn't working
- Fixed bug where null wasn't displayed in union types
- Fixed bug where the editor displayed above the "open map" menu
- Fixed bug where deepPermissive didn't apply permissive deeply
- Fixed AceEditorAdapter.renderer.scrollBy typo/bug
